# Interaktivn-gener-tor-a-editor-koln-ho-rozvrhu
Vytvořte v prostředí Visual Studio (jazyk C#) desktopovou aplikaci pro Windows Forms s verzováním na GitHubu. Aplikace bude sloužit jako jednoduchý vizuální editor školního rozvrhu s možností správy základních seznamů tříd, učitelů, učeben a předmětů.

Uživatelské rozhraní nabídne týdenní mřížku rozvrhu s přepínáním zobrazení podle vybrané třídy nebo učitele a umožní manuální vkládání vyučovacích hodin do mřížky. Aplikace bude v reálném čase hlídat základní dvojité kolize (překrývání výuky jednoho učitele nebo obsazení jedné učebny ve stejném čase) a vizuálně na ně upozorňovat.

Veškerá vytvořená data se budou ukládat a načítat ze strukturovaného souboru ve formátu JSON nebo XML.
